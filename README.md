# DiveEnd

沉浸式论文收集与AI翻译阅读工具 - 一站式探索学习新领域

## 功能特点

- 🔍 **DeepStart** - 根据自然语言查询自动搜索论文，AI帮助分类整理
- 📖 **DeepRead** - AI翻译+摘要，原文与翻译分离布局，沉浸式阅读
- 🗂️ **文库管理** - 按文件夹分类管理论文
- 🔌 **支持多LLM** - OpenAI GPT 和 Anthropic Claude API 格式都支持
- ☁️ **百度云同步** - 本地数据自动同步到百度云
- 💻 **三栏布局** - 流畅自然的探索流程，Claude风格UI

## 编译运行

### 依赖
- Go 1.20+
- SQLite

### 编译
```bash
go build -o diveend ./cmd/server
```

### 运行
```bash
./diveend
```

然后打开浏览器访问 `http://localhost:8080`

## 配置

首次打开后，在左侧面板配置：
1. **LLM设置** - 选择提供商（OpenAI/Anthropic），填入API Key和模型名称
2. **百度云同步**（可选）- 填入AK/SK开启自动同步

## 使用流程

### DeepStart 探索新领域
1. 在DeepStart标签页输入你的查询，例如："我想查询和llm code agent相关的论文"
2. 点击"开始探索"，系统会自动在arXiv搜索论文，并使用AI进行分类
3. 勾选你想要导入的论文，选择文件夹，点击导入
4. 论文就会出现在右侧文库列表中

### DeepRead 沉浸式阅读
1. 在右侧点击你要阅读的论文，自动切换到DeepRead
2. 粘贴需要翻译的论文内容（按章节），填写章节名称
3. 点击"一键AI翻译"，AI会生成翻译和要点总结
4. 翻译结果保存在数据库，可以随时回看

- **LLM**: OpenAI / Anthropic API
